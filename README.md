# SENSE

> Alt text for physical reality, plus an agent that can read it safely.

**Status: hackathon-grade prototype. Everything in the default demo is simulated and labelled as such.**

_(Full README is written in milestone M13; this is the M0 stub.)_

## Limitations notice

SENSE is **not** a medical device and **not** a certified safety system. It must not be relied on
for life-safety decisions. Simulated data is labelled "SIMULATED WORLD". Identity checks are
"ANS-modeled", not ANS-compliant. The app targets WCAG 2.2 AA but is not certified.

## Quickstart

```
npm install
npm run verify
```

If you have no Node installed, the autonomous build placed a portable one in `.tools/node`
(`source .sense/env.sh` puts it on your PATH).
